# Deadlock — онлайн-драфт для турниров

Captains Mode 6v6: монета, баны и пики по очереди, таймер с резервом.
Каждый капитан ходит со своего устройства. Без зависимостей, только Node.js 18+.

## Запуск
    node server.js            # http://localhost:3000
    PORT=8080 node server.js  # другой порт

Для игры по интернету разместите на любом хостинге с Node (VPS, Render, Railway, Fly.io)
или откройте порт через туннель (cloudflared, ngrok).
За прокси (nginx) отключите буферизацию для SSE: `proxy_buffering off;`.

## Как пользоваться
1. Судья открывает сайт, задаёт команды и героев, жмёт «Создать комнату».
2. Появляются 4 ссылки: судья, капитан 1, капитан 2, зрители. Личные ссылки отправьте капитанам.
3. Дальше всё идёт по порядку: монета, очередность, сторона, 8 банов и 12 пиков.

## Устройство
- `server.js` — сервер: состояние комнат в памяти, проверка прав и правил, таймеры, SSE-рассылка.
- `public/index.html` — клиент (один файл).
- Права определяются секретными токенами в ссылках, ход чужой команды сервер отклоняет.
- Комнаты живут в памяти 48 часов и пропадают при перезапуске сервера.
- Список героев задаётся при создании комнаты, его можно править под патч.
